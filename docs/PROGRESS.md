## 怎么加一行

合并完 PR，把这一行填上：

```
| 4 | YYYY-MM-DD | 题目 | N | N | +N / −N | N |
```

数字从哪来：

```powershell
# 提交数、文件数、改动量（相对第一父，即这个 PR 带来的实际改动）
git diff --shortstat <merge>^1 <merge>
git rev-list --count <merge>^1..<merge>

# 测试数
python -m pytest -q
```
